Create a square, cropped character portrait using the supplied character reference as the authority for the character's identity and design.

Preserve the actual hair shape and color, face, ears or other species features, outfit layers, colors, trim, and accessories. Preserve the original light-versus-dark arrangement of the clothing.

Reinterpret a small character sprite as a proper illustrated portrait. Do not preserve its tiny full-body scale, black background, pixel-like simplification, or original framing.

STYLE CONSISTENCY:
When a style reference is supplied, use it as the fixed visual standard for the portrait.

The goal is not merely to create a portrait inspired by the reference. The result should belong to the same portrait set and appear to have been produced using the same drawing and rendering conventions.

Keep the style stable even when the character design changes.

Match the reference's line quality, typical line thickness and variation, edge softness, shading technique, shadow complexity, texture, amount of detail, rendering density, and overall degree of polish.

Do not allow the character sprite's simplicity, resolution, pixel-like appearance, or rendering style to influence the final drawing style.

Character-specific features must come from the character reference, but differences between characters should not cause changes in the underlying rendering style.

Do not independently beautify, modernize, simplify, exaggerate, or reinterpret the supplied style. Avoid drifting toward generic anime illustration, chibi, vector art, mascot art, sticker art, glossy digital painting, or polished anime key visuals.

Across different characters, maintain the same drawing conventions and approximately the same rendering complexity as the style reference.

If no style reference is supplied, use a restrained hand-drawn anime-inspired game portrait style with expressive line weight, simple cel shading, muted colors, and moderate detail.

COMPOSITION:
Create a three-quarter-view bust portrait.

Keep the entire head, hair, ears, horns, or headwear inside the frame. The head should occupy roughly half the canvas height, with both shoulders and a meaningful portion of the upper torso visible.

Use approximately the same portrait scale and framing across different characters. Turn the face slightly rather than using a perfectly symmetrical front view.

Crop the torso naturally at the bottom edge.

BACKGROUND:
Use a simple, roughly uniform pink #E69EB1 background for later background removal.

No scene, objects, text, border, or decorative background elements.
